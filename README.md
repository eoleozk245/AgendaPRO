# AgendaPRO

Plataforma de agendamento de serviços para barbearias e salões. Em construção (Etapa 1: fundação).

## Requisitos

- Node.js 22 ou superior

## Comandos

```bash
npm install          # instala as dependências
npm run dev          # servidor de desenvolvimento
npm run build        # verifica tipos e gera a versão de produção em dist/
npm run typecheck    # só verifica os tipos do TypeScript
npm run lint         # ESLint
npm run format       # formata o código com Prettier
npm run format:check # confere a formatação sem alterar nada
npm test             # roda os testes uma vez (Vitest)
npm run test:watch   # testes em modo observação
```
